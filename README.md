En esta actividad desarrollé una caja de música interactiva que combina elementos de audio, visualización en tiempo real y efectos gráficos animados utilizando tecnologías web modernas. El objetivo principal fue crear una experiencia inmersiva donde los gráficos reaccionen dinámicamente al ritmo y las frecuencias de la música, implementando un sistema de análisis de audio mediante la Web Audio API y visualización mediante HTML5 Canvas.
Este proyecto me permitió explorar la integración entre el dominio sonoro y el visual, aplicando conceptos de programación orientada a eventos, manipulación del DOM y animaciones fluidas con requestAnimationFrame. El resultado final supera la consigna básica, incorporando un diseño estético con tema futurista y efectos visuales sincronizados con la música.
